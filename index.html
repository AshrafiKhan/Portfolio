Live Demo (opens in a new tab)
  • HTML
  • CSS
  • Vanilla JavaScript
  • GSAP
  • ScrollTrigger & Flip
  • Lenis
  • Responsive Design
  • Progressive Enhancement

Challenge

Design and build a bright, animation-heavy landing page for a fictional multi-cuisine food court, with rich motion and interactivity, while keeping it framework-free and fully usable when animations or JavaScript are unavailable.

My Contribution

  • Built a seven-section single-page site in static HTML, CSS and vanilla JavaScript, with no build step.
  • Animated it with GSAP and Lenis: split-letter hero reveal, parallax photo collage, scroll-linked marquee, magnetic buttons and 3D card tilt.
  • Built a 24-dish menu filtered by cuisine with GSAP Flip transitions, plus a detail modal for every dish.
  • Added a live happy-hour countdown, count-up stats, a keyboard-navigable gallery lightbox and a validated booking form.

Highlights

  • Respects reduced-motion settings by skipping smooth scroll, animations and the preloader.
  • Renders the full page even if the animation CDN or JavaScript fails.
  • Plain static files that deploy to any host, live on GitHub Pages.
